Machine Learning Algorithm Framework

Twelve widely used algorithms, organized by how they learn and where they are applied: tabular data, computer vision, natural language processing and generative AI.

How to read this framework

Supervised: learns from examples that already have the correct answer (labels)
Unsupervised: finds structure in data without labels (includes self-supervised learning)
Primary domain: where the algorithm is most commonly used
Also used: a real but less common application

02

How Each Algorithm Works

A short explanation of each algorithm, with real-world examples of where it is used today.

Supervised learns from labeled examples

Linear Regression

SupervisedTabular
How it works
Fits the straight line (or flat plane) that best matches the data by minimizing the squared gap between predicted and actual values.
Real-world use
Estimating home prices from size and location; forecasting monthly sales.

Logistic Regression

SupervisedTabularNLP
How it works
Adds up weighted features, then passes the total through an S-shaped sigmoid curve to produce a probability between 0 and 1.
Real-world use
Predicting whether a borrower will default; filtering spam emails based on word counts.

Decision Tree

SupervisedTabular
How it works
Asks a series of yes or no questions about the features, choosing each split to make the resulting groups as pure as possible, until it reaches a final answer.
Real-world use
Loan approval rules that auditors can read; patient triage checklists.

Random Forest

SupervisedTabular
How it works
Trains hundreds of decision trees, each on a random sample of rows and features, then lets them vote. Combining many trees cancels out individual mistakes.
Real-world use
Credit card fraud detection; predicting which customers will cancel a subscription.

Gradient Boosting (XGBoost)

SupervisedTabular
How it works
Builds small trees one after another, with each new tree focusing on the errors that the previous trees made.
Real-world use
Credit scoring at banks; ranking search and ad results; a frequent winner of data science competitions on tabular data.

K-Nearest Neighbors (KNN)

SupervisedTabularVision
How it works
Stores the training data and labels a new item by a majority vote among the K most similar examples, measured by distance.
Real-world use
"Customers like you also bought" recommendations; recognizing handwritten digits.

Convolutional Neural Network (CNN)

SupervisedVisionGenerative AI
How it works
Slides small learned filters across an image to detect edges, then shapes, then whole objects, one layer at a time.
Real-world use
Detecting tumors in medical scans; face unlock on phones; spotting defects on assembly lines.
Unsupervised finds structure without labels

K-means Clustering

UnsupervisedTabularVision
How it works
Places K center points, assigns every item to its nearest center, moves each center to the middle of its group, and repeats until the groups stop changing.
Real-world use
Segmenting customers for targeted marketing; reducing the number of colors in an image.

Principal Component Analysis (PCA)

UnsupervisedTabularVision
How it works
Finds the few directions that capture the most variation in the data and describes every item using only those, shrinking many features into a handful.
Real-world use
Compressing hundreds of sensor readings before modeling; early face recognition systems (eigenfaces).

Transformer (BERT, GPT)

Unsupervised (self-supervised)NLPGenerative AIVision
How it works
Uses attention so each word can weigh every other word in the text. It is pretrained on huge amounts of unlabeled text by predicting missing or next words, then often fine-tuned with labeled data.
Real-world use
Chat assistants such as ChatGPT and Gemini; Google Translate; BERT improving Google Search results.

Generative Adversarial Network (GAN)

UnsupervisedGenerative AIVision
How it works
Two networks compete. A generator creates fake samples, a discriminator tries to catch them, and both improve until the fakes look real.
Real-world use
Photorealistic faces (StyleGAN); upscaling low-resolution photos; creating synthetic training data.

Diffusion Model

Unsupervised (self-supervised)Generative AIVision
How it works
Learns to reverse a process that slowly adds noise to images. To generate, it starts from pure noise and removes it step by step, guided by a text prompt.
Real-world use
Text-to-image tools such as Stable Diffusion, DALL·E 3 and Midjourney.
03

How the Algorithms Connect

These algorithms are not isolated. Many newer methods are built directly on older ones. The columns follow the familiar progression from machine learning to deep learning to generative AI.

One neuron is a logistic regression.A neural network stacks many of these units in layers. Adding filters creates a CNN for images, and adding attention creates a Transformer for language.
Trees become teams.Random Forest averages many independent trees (bagging), while Gradient Boosting trains trees in sequence so each one fixes earlier errors (boosting).
Similar names, different learning.KNN and K-means both measure distance, but KNN needs labels to classify, while K-means groups unlabeled data on its own.

How the Algorithms Were Classified

Learning typeAn algorithm is supervised if training requires labeled answers. It is unsupervised if it learns patterns from unlabeled data. Self-supervised models create their own training targets from raw data, so they are grouped with unsupervised learning.
Application domainDomains are based on the type of input data the algorithm is mainly built for: rows and columns (tabular), images (vision), text (NLP), or creating new content (generative AI).
Primary versus secondaryA filled dot marks the domain where the algorithm is standard practice today. An open dot marks a real but less common use, such as K-means for compressing image colors.
