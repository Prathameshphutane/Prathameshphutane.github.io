Machine Learning Algorithm Framework

A visual reference that classifies twelve machine learning algorithms by learning type and application domain, shows how they build on one another, and helps readers choose the right one for a problem.

Introduction

When I started learning about machine learning, one of the hardest parts was not understanding a single algorithm. It was seeing how all of them fit together. Names like Random Forest, K-means, Transformer and GAN show up everywhere, but it is not obvious which ones need labeled data, which kind of data they work on, or how a newer method relates to an older one.

This framework is my answer to that problem. It puts twelve widely used algorithms on one page and organizes them so a reader can quickly compare them and pick the right tool for a task.

Description

The framework is an infographic built as a web page, with downloadable PDF and PNG versions. It is organized into five parts:

  1. Algorithms at a Glance: a matrix of all twelve algorithms, grouped as supervised or unsupervised, with dots showing their primary and secondary domains across tabular data, computer vision, NLP and generative AI, plus a summary of the most common choice in each domain.
  2. How Each Algorithm Works: a card for every algorithm with its learning type, domains, a plain-language explanation and real-world examples.
  3. How the Algorithms Connect: a family tree that moves from classical machine learning to deep learning to generative AI and shows how methods build on each other, such as decision trees leading to Random Forest and Gradient Boosting.
  4. Choosing the Right Algorithm: a two-question decision guide based on whether labels exist and what kind of data or output is needed.
  5. How the Algorithms Were Classified: the criteria I used to assign each learning type and domain, so the classification can be checked.

The algorithms covered are Linear Regression, Logistic Regression, Decision Tree, Random Forest, Gradient Boosting (XGBoost), K-Nearest Neighbors and Convolutional Neural Networks on the supervised side, and K-means, Principal Component Analysis, Transformers, Generative Adversarial Networks and Diffusion Models on the unsupervised and self-supervised side.

Objective

The goal was to create a clear and accurate reference that identifies and categorizes key machine learning algorithms, illustrates their main application domains, and gives practical examples of how each one is used. I also wanted to practice explaining technical ideas in a way that someone new to the field could follow.

Process

  1. Research. I reviewed the course resources on the differences between AI, machine learning, deep learning and generative AI, then read the original papers and official documentation for the more advanced algorithms to make sure my explanations were accurate.
  2. Selecting the algorithms. I chose twelve algorithms so that every domain had strong coverage and so the list included both classic methods and the newer models behind generative AI.
  3. Setting classification rules. Before placing anything, I defined clear criteria: an algorithm is supervised if training needs labeled answers, and its domain depends on the type of data it is mainly built for. I separated primary uses from secondary ones so the framework would not overstate where an algorithm is used.
  4. Handling edge cases. Transformers and Diffusion Models do not fit neatly into supervised or unsupervised, because they create their own training targets from unlabeled data. I grouped them as self-supervised under unsupervised learning and explained why on the framework.
  5. Mapping relationships. I sketched how the algorithms build on each other and arranged them into three columns that follow the progression from machine learning to deep learning to generative AI.
  6. Design and build. I used two consistent colors for the learning types, filled and open dots for domain strength, and a numbered layout that reads from overview to detail. I built it in HTML, CSS and SVG so it stays sharp on any screen and can be exported as a PDF.
  7. Review. I checked every classification and example against my sources, tested the layout on desktop and mobile, and fixed overlapping labels in the diagram.

Value Proposition

This artifact shows that I can take a large, technical subject and organize it into something accurate, structured and easy to use. Classifying algorithms correctly requires understanding how each one learns, not just what it is called. Presenting that clearly to a non-expert audience is a skill I use every day when turning complex tax rules into system logic at work.

Unique Value

Most algorithm cheat sheets are simple lists. This framework goes further in three ways. It separates primary from secondary domains instead of treating every use as equal. It shows the relationships between algorithms, such as the fact that a single neuron is essentially logistic regression. And it ends with a practical decision guide, so the reader leaves knowing which algorithm to try next, not just what each one is.

Relevance

Choosing the wrong algorithm is one of the most common and costly mistakes in machine learning projects. Generative AI gets most of the attention, but many business problems are still solved best with classical methods like gradient boosting on tabular data. This framework helps students, analysts and engineers match the method to the problem, and it will serve as my own reference throughout the AI program and in future projects.

Key takeaway: tabular data is still dominated by tree-based models, images by CNNs, and language by Transformers, while generative AI is built mostly on unsupervised and self-supervised learning at very large scale.
